# Aplikasi Manajemen Surat dan Disposisi

Aplikasi berbasis web untuk mengelola surat masuk, surat keluar dan disposisi surat di lingkungan organisasi. Dibangun menggunakan Laravel framework.

## Fitur Utama

- Manajemen surat masuk dan surat keluar
- Disposisi surat secara elektronik
- Dashboard monitoring surat
- Pencarian dan filter surat
- Manajemen pengguna dan hak akses
- Notifikasi disposisi

## Teknologi

- Laravel 10
- MySQL Database
- Bootstrap 5
- DataTables
- Font Awesome Icons

## Instalasi

1. Clone repository ini
2. Install dependencies dengan composer
3. Copy .env.example ke .env dan sesuaikan konfigurasi
4. Generate app key dengan `php artisan key:generate`
5. Jalankan migrasi database dengan `php artisan migrate`
6. Jalankan server dengan `php artisan serve`
